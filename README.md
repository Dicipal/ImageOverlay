# 🎨 Image Tracer Overlay
A Chrome extension for **Skribbl.io**. This tool allows you to overlay reference images directly onto your browser canvas with adjustable opacity, scale, and rotation.

> [!NOTE]
> This extension is optimized for **Skribbl.io**. The "Auto" fetch feature relies on Skribbl's specific UI to detect the active word.

## 🛠 Installation Guide
Follow these steps to install the extension locally:

### 1. Download the Source Code
Choose one of the following methods:
* **Option A:** Click the green **Code** button at the top of this repository and select **Download ZIP**. Extract the folder to your computer.
* **Option B:** Clone the repo using Git

### 2. Prepare Chrome
1. Open Google Chrome and go to: `chrome://extensions/`
2. In the top-right corner, toggle **Developer mode** to **ON**.

### 3. Load the Extension
1. Click the **Load unpacked** button in the top-left.
2. Navigate to your `ImageOverlay` folder.
3. ⚠️ **IMPORTANT:** Select the folder inside named `dist` and click **Select Folder**.

### 4. Start Drawing
The extension icon should now appear in your toolbar. Head over to **Skribbl.io**, pin the extension, and you're ready to go!
